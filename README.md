# Mumtea High

The website is `index.html`, published from this folder by GitHub Pages:
https://mohamed200215.github.io/mumtea-high/

## What's in this folder

**The website uses these, so don't rename or move them:**

| Name | What it is |
|---|---|
| `index.html` | The published website. Generated by the build, so don't edit it by hand. |
| `mumtea-high.html` | The page's starting point. The build fills it in and copies it to `index.html`. |
| `backgrounds/` | Page patterns: skulls, leopard, zebra, plaid. |
| `emblems/` | The skull icons for ID cards and bank cards. |
| `emoji/` | Emoji pictures. |
| `figures/` | Animated pictures on the home page. |
| `sounds/` | Theme song and game sounds. |
| `preview.jpg` | The picture that shows when the link is shared in a message. |

**Used to make the website:**

| Name | What it is |
|---|---|
| `src/` | The code: games, shop, camera, filters and styles. |
| `tools/` | The build script. Run `npm run build` after changing anything in `src/`. |
| `supabase/` | The database setup, plus two small server functions: `login` and `remove-student`. |
| `package.json`, `package-lock.json`, `tsconfig.json` | Project settings. |
| `node_modules/`, `build/` | Created automatically. Safe to ignore. |

**Yours, kept on this computer only (not published):**

| Name | What it is |
|---|---|
| `source-images/filters/` | Pictures for camera filters, one folder per filter. **Put new filter folders here.** |
| `source-images/logos/` | Original pictures for game logos and home page figures. |
| `source-images/icons/` | Original skull icon pictures. |
| `source-images/other/` | The font file, the original game-over sound and other originals. |
| `backups/` | Old copies of the page from before big changes. |

`source-images/` and `backups/` aren't on GitHub, so OneDrive is their only backup.
